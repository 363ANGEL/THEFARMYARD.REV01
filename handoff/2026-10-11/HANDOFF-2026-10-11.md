## Poker Room rules
1. One game at a time. Everyone sees START until any member presses it; then START is greyed for all and CLOSE shows for all.
2. Game Checklist border: slow teal breathe when idle, slow red breathe while a game is live.
3. Initiator pastes the PokerNow link (PASTE → OPEN TABLE → GO TO TABLE). Only the initiator sees the link box. Until OPEN TABLE: other members see "WAITING FOR TABLE TO OPEN", seats locked, clicking a seat shows that tip.
4. Initiator's seat shows taken once the table opens.
5. Held seats: a seat someone has picked but not confirmed shows "HELD · name" (pink dotted) and can't be picked; short-lived reservation, realtime to all.
6. CLOSE: allowed straight away if nobody sat. If anyone sat, FILE DOCKET must be pressed first; otherwise show the reminder tip. Backend: max one open `poker_table`; `close_table` rejects if a seated game has no filed result.
7. Table Docket shows whenever a game is open; rows hover-glow. CLOSE hover = brighter red, START hover = green flicker.
8. League Board: rank by buy-ins ÷ wins (lower better); ties → more wins → fewer buy-ins → higher £ → name. Icons: 1st gold crown, 2nd silver queen ♛, 3rd copper bishop ♝. Poker Debts box uses the same thin glow as the League Board.
9. Buy-in +/− play `assets/cluck-happy.mp3` / `assets/cluck-sad.mp3`.
10. New modules (see BUILD-PLAN "Poker Room feeds"): Poker Scandal Sheet (5 daily stories + og:image previews) and Poker School (5 YouTube videos ≤5 min, by views).

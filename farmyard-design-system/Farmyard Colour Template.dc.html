05 · Rules

  • Neon is a line, text or glow — never a filled area.
  • One pink thing per view carries the glow animation; the rest hold still.
  • Teal borders, pink content inside them. Don't put pink borders around teal text.
  • Glow recipe: 0 0 6px colour, 0 0 14px colour@.45–.55, inset 0 0 6px colour@.2–.35.
  • Text sits on neutral-200/300/400 for hierarchy, never on dimmed neon.
  • No pure black or white; the ground is Nocturne's #161826.

06 · Paste into any page

:root {
  --neon-pink: #ff3fa4;        --neon-pink-link: #ff8ccb;  --neon-pink-hover: #ffb3dc;
  --neon-teal: #5fd3cf;
  --haze-pink: rgba(45,15,34,.85);   --haze-teal: rgba(27,74,74,.45);
  --glow-pink: 0 0 6px #ff3fa4, 0 0 14px rgba(255,63,164,.55), inset 0 0 6px rgba(255,63,164,.35);
  --glow-teal: 0 0 6px #5fd3cf, 0 0 14px rgba(95,211,207,.45);
  --rule-teal: rgba(95,211,207,.35);
  --color-accent: var(--neon-pink);   /* overrides Nocturne's blurple */
}
body { background: radial-gradient(900px 600px at 80% 10%, var(--haze-pink), transparent 60%),
                   radial-gradient(700px 500px at 0% 100%, var(--haze-teal), transparent 60%),
                   var(--color-bg); }
